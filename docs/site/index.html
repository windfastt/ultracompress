Why UltraCompress Exists

Built for real mixed directories — not single-file synthetic demos

7-Zip, Zstandard, WinRAR, and PeaZip are excellent single-codec engines, yet all of them apply one global codec and level blindly across heterogeneous input.

Problem 1 · Wasted CPU Hours

Grinding heavy codecs on MP4 & JPEG

Running LZMA2 -mx=9 or zstd -19 on 10 GB of H.265 video or camera JPEGs burns 16 CPU threads for up to 41 minutes to save < 0.1%. UltraCompress detects >= 7.85 bpb multi-window entropy in milliseconds and streams raw blocks at NVMe speed with cryptographic hashes.

Problem 2 · 20–50% Missed Savings

Raw codecs miss stride, delta & duplicates

Without per-stream ByteShuffle on 4/8-byte database columns, 3-channel Delta on uncompressed rasters, X86Bcj on binaries, and cross-folder SHA-256 deduplication, uniform codecs leave gigabytes of recoverable lossless savings on disk and in cloud storage.

Data Safety Guarantee

Four Strict OperationKind Modes — Zero Silent Mutation

Lossless archiving is never conflated with destructive re-encoding or metadata stripping. Core contracts, Engine IPC, CLI, and Desktop UI enforce a hard boundary across four distinct modes.

1. Lossless Compression

Default · All 5 Profiles

Bit-for-bit restoration of every stream, timestamp, attribute, and folder hierarchy inside indexed .ucx containers.

  • Verification: Per-block XXH64 + per-file & archive SHA-256 digests.
  • Zero Mutation: Never re-quantizes JPEGs, never alters MP4 streams, never strips EXIF or debug symbols.
  • Inflation Guard: Blocks >= 99.8% of raw size automatically store uncompressed.

2. Lossy Optimization

Studio Only · Consent Required

Intentional perceptual media size reduction (e.g., exporting WebP/AVIF delivery assets from camera JPEGs/PNGs).

  • Mandatory Preview: Side-by-side visual split-view with SSIM / PSNR score & byte delta before arming.
  • Explicit Gate: Requires ConsentConfirmation checkbox or --consent-lossy flag.
  • Safe Output: PreserveOriginal = true locked by default (writes separate output copy).

3. Format Conversion

Studio Only · Consent Required

Explicit container or schema migration where file representation intentionally changes (BMP/TIFF → lossless PNG, CSV → Parquet, .zip → .ucx).

  • Diff Preview: Displays exact source-to-target container, extension, and compatibility changes upfront.
  • Explicit Gate: Never triggered automatically during standard compression jobs.
  • Safe Output: Preserves untouched source files by default (PreserveOriginal = true).

4. Data Removal (Hygiene)

Manifest + Consent Required

Targeted privacy and build hygiene: stripping GPS/camera serial EXIF tags, PDB/DWARF debug symbols, or build caches.

  • Itemized Manifest: Lists every tag, symbol stream, or path scheduled for removal with exact byte counts.
  • Explicit Gate: Requires AcknowledgeDataRemoval confirmation or --consent-remove-data.
  • Safe Output: Emits sanitized copy; original files remain intact by default.
