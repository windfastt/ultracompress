Profiles at a glance

Start fast; escalate only when the bytes matter.

  • BalancedDefault recipe, moderate zstd — under ~30s for typical files.
  • SmallStronger compression for everyday “make it smaller” use.
  • TinyHigh effort; future multi-candidate tournaments with time budgets.
  • LaboratoryMaximum effort, manual recipes, optional lossy transforms.
  • ExperimentalPlugins and PAQ-family codecs — download on first use, crash-isolated.

Simple, separable architecture

UI stays responsive; the engine owns scheduling; workers own risk.
